# ⚾ KBO 알림 봇

KBO 경기 일정과 선발 라인업을 텔레그램으로 알려주는 봇입니다.

## 사용 방법

텔레그램에서 **[@eubene_k_bot](https://t.me/eubene_k_bot)** 을 검색하거나 링크를 눌러 시작하세요.

```
1. /start  →  봇 시작
2. /myteam →  응원 팀 선택 (버튼 클릭)
```

팀을 선택하면 경기 당일 오전 10시에 일정 알림, 라인업이 나오면 바로 알려드려요.

## 지원 팀

🦅 한화 · 🐯 KIA · ⚡ LG · 🐻 두산 · 🔴 SSG · 🦁 삼성 · 🦕 NC · 🧙 KT · 🌊 롯데 · 🦸 키움

## 주요 알림

| 알림 | 시각 |
|---|---|
| 경기 일정 (상대팀·선발투수·구장·KBO 전체 경기) | 매일 오전 10시 |
| 선발 라인업 (타순·선발투수) | 라인업 발표 즉시 |
| 경기 취소 | 취소 확인 즉시 |
